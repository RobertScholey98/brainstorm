**Hypothesis.** For a person starting work from a thread in the project they mean, asking only what can't be inferred should make the first message the whole decision, because the project and branch come from the thread, at the cost of hiding the project choice behind a Change link.

**Tradeoff.** The project is a default, not a question. A wrong inference costs a detour through Change, and someone who works across projects takes that detour every time.
